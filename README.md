# Data Visualization and Storytelling

## Task 2: Data Visualization and Storytelling

### Objective
The objective of this project was to analyze sales data and create visualizations that communicate important business insights clearly.

### Dataset
The project uses the Superstore sales dataset containing 10,800 records and 21 columns.

The dataset includes information about:
- Orders
- Customers
- Categories
- Sub-categories
- Regions
- Sales
- Quantity
- Discounts
- Profit
- Order dates

### Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

### Visualizations Created

The dashboard contains the following visualizations:

1. **Sales by Category**
   - Compares total sales across Furniture, Office Supplies, and Technology.

2. **Profit by Category**
   - Shows which product categories generate the most profit.

3. **Sales by Region**
   - Compares sales performance across different geographical regions.

4. **Sales vs Profit by Category**
   - Compares revenue and profitability across product categories.

5. **Monthly Sales Trend**
   - Shows how sales change over time.

6. **Key Business Metrics**
   - Total Sales
   - Total Profit
   - Total Orders
   - Units Sold

### Key Insights

- Technology and Furniture are important contributors to overall sales.
- Sales and profit do not always increase together, highlighting the importance of monitoring profitability rather than sales alone.
- Regional performance varies, providing opportunities to identify stronger and weaker markets.
- Monthly sales trends can help identify changes in demand over time.
- Business decisions should consider both sales and profit rather than relying on a single metric.

### Data Visualization Principles Applied

- Used bar charts for categorical comparisons.
- Used a line chart to show the monthly sales trend.
- Avoided unnecessary visual clutter.
- Used clear chart titles and axis labels.
- Focused on business insights rather than decoration.
- Combined multiple visualizations into a single dashboard for easier interpretation.

### Files in This Repository

- `Superstore.csv` - Original dataset used for analysis.
- `superstore_dashboard.png` - Final visualization dashboard.
- `.ipynb` file - Google Colab notebook containing the Python code used to create the visualizations.

### Conclusion

The project demonstrates how sales data can be transformed into visual insights using Python. The dashboard provides a concise overview of sales, profitability, regional performance, and trends to support data-driven business interpretation.
